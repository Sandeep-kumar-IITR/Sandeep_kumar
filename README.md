# Personal Website (Earlier Version)

A static personal website built with HTML, CSS and Bootstrap. The page includes sections for a short introduction, skills, achievements and projects.

## Run locally

Clone the repository and open `index.html` in a browser. If the browser blocks local assets, start a local web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Files

- `index.html` — main page.
- `index.css` — page styling.
- `Project.html` — project section/page.
- Image and certificate assets — used by the page.

## Context

This is an earlier portfolio site and is retained as a record of previous web work. For current experience and selected projects, see the profile README.
